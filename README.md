# Lab Activity 3.2: CSS Styling

## 📌 Introduction

This lab activity focuses on applying CSS styling techniques to create a simple and visually organized Campus Café website.

The project demonstrates how external CSS can be used to customize backgrounds, text, fonts, links, lists, and other HTML elements while maintaining a consistent appearance across multiple web pages.

## 🎯 Objectives

- Apply CSS background colours, images, repetition, and positioning.
- Use background shorthand properties.
- Style text using font families, sizes, spacing, and alignment.
- Apply different link states using CSS pseudo-classes.
- Customize ordered and unordered list markers.
- Use an external stylesheet across multiple HTML pages.

## 📝 Lab Activities

### Part A: Create the Page Content

Created the main Campus Café webpage using HTML5.

**Tasks completed:**
- Created the `menu.html` and `about.html` pages.
- Added a café heading and tagline.
- Included an introduction and daily special offer.
- Created navigation links between the pages.
- Added popular food choices using an unordered list.
- Added ordering instructions using an ordered list.
- Created a menu table displaying food categories and prices.
- Added a footer containing a pricing note.

### Part B: Backgrounds and Colour

Applied CSS background properties to improve the appearance of the website.

**Tasks completed:**
- Set the webpage background colour to `#f5f7fa`.
- Applied a pale blue background to the header.
- Created a 24 × 24 pixel decorative image (`tile.png`).
- Tested `repeat`, `repeat-x`, `repeat-y`, and `no-repeat`.
- Explored background positioning and attachment.
- Applied background shorthand with `no-repeat right top`.

### Part C: Text and Font Styling

Used CSS typography properties to improve readability and presentation.

**Tasks completed:**
- Applied Arial with a sans-serif fallback.
- Set the base font size to 16px.
- Styled the main heading with navy text and letter spacing.
- Transformed the tagline into uppercase italic text.
- Applied justified alignment and indentation to the introduction.
- Highlighted the daily special offer using bold maroon text.
- Underlined section headings.
- Styled the footer using the CSS font shorthand property.

### Part D: Links and Lists

Customized navigation links and list markers using CSS.

**Tasks completed:**
- Applied `:link`, `:visited`, `:hover`, and `:active` pseudo-classes.
- Used different colours for each link state.
- Changed unordered list markers to squares.
- Changed ordered list markers to uppercase Roman numerals.
- Tested a custom 12 × 12 pixel marker image (`marker.png`).
- Restored square markers after testing.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `menu.html` in a web browser.
4. Use the navigation links to access the menu and About Us pages.
5. Modify `menu.css` to experiment with different CSS properties.
